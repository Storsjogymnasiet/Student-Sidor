Internets historia

Hur skapades internet?

Vad var Arpanet

År 1969 startades Arpanet men idén till det formuleras år 1963. Tanken med Arpanet var att kunna kommunicera via text på datorer. Arpanet är även känt som starten på internets historia

World Wide Webb

Tim Berners-Lee var grunden till skapandet utav World Wide Web. Året var 1989 när World Wide Web skapades. WWW skapades för att enkelt länka till och mellan saker

Vilken var den första webbsidan?

Under år 1989 skapades den första webbsidan vid namnet info.cern.ch. Info.cern.ch innehöll länkar som ledde till andra sidor. Webbsidan användes för att skapa en plats där människor kan delas information över världen via dokument och länkar.

Vilken var den första stora webbläsaren?

Den första webbläsaren som blev stor och oerhört populär hette Mosaic som senare blev till Netscape Navigator. Året var 1993 när webbläsaren Mosaic släpptes. Mosaic var viktigt för webbens utveckling då dem var först med att kunna vissa bilder med text

Vad är en IP-adress och DNS?

IP-adressen är en unik identifierare som används för att koppla samman enheter i ett nätverk. En DNS översätter domännam till ip-adressen som gör så att datorer kan hitta rätt webbplats på internet. En DNS behövs för att datorn ska hitta rätt webbplats på internet.

Vilken var Sveriges första hemsida?

Året var 1993 och första svenska hemsidan grundades utav Per Hedbor vid namnet Lysator. Lysator innehöll information osv om datorföreningen Lysator. Webbsidan finns kvar än idag och används fortfarande

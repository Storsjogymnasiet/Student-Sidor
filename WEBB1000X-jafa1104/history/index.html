Webbens Historia

ARPANET

ARPANET startades 1969 och var världens första paketväxlande datornätverket och den gjorde så man kunde koppla ihop datorer och dela information. Det var också grunden till internetet som vi har idag.

WWW

Tim Berners-Lee var personen som skapade the World Wide Web år 1989 för att hjälpa forskare med att dela information mellan datorer.

FÖRSTA HEMSIDAN

Den första hemsidan skapades den 6 augusti 1991. Den innehöll text, hyperlänkar, instruktioner och information om WWW. Hemsidan var använd för att visa hur man kunde skaffa tillgång till andra dokument.

FÖRSTA STORA WEBBLÄSAREN

Den första stora webbläsaren var Mosaic som kom 1993. Mosaic var väldig viktig för den var världens första webbläsare med bilder, videor och ljud.

IP-ADRESS

IP-adresser är unika sätt av nummer som alla saker som har anslutning till nätverket får. DNS gör webbadresser till IP-adresser som webbläsaren kan läsa. Vi behöver DNS för att kunna söka med webbadresser.

SVERIGES FÖRSTA HEMSIDA

Sveriges första hemsida publicerades 1993 som fortfarandes finns kvar. Den blev gjord av Datorföreningen Lysator vid Linköpings universitet. Hemsidan innehöll information om datorföreningen.

Some intresting internet history facts

What was ARPANET?

APRANET was one of the first computer networks and started development back in 1960s. It was created to mainly be a way for different computers at different devices at different locations to communicate and share information like between eachother.

Who created the World Wide Web?

Well, he had the idea of the World Wide Web in 1989 and in 1990, Tim Berners-Lee had created the first web server and browser. But why would he create the World Wide Web if ARPANET already existed? Because ARPANET had no easy way to organise the information that was sent.

What was the first wesbite?

It’s info.cern.ch which was made by Tim Berners-Lee in 1990 and it’s main goal was to simply explain what the World Wide Web was created for. And so obviously, it contained the information about the World Wide Web and how it worked.

What was the first major browser?

Well, the first major web browser was called NCSA Mosaic, it was released during 1993 on april the 21th. But why did it become important when developing the web? Well, it was easy to use and even had a graphical interface.

What are IP adresses and DNS?

An IP adress is a device’s/internets adress which can be used to identify them. To know where information was sent from and where it should go. DNS? Well, DNS is short for Domain Name System. And it is a system that makes it easy to remember domain names with their responding IP adresses. Now, when we connect to the web IP adresses can be difficult to remember. When you enter a website DNS helps connect you to the right server.

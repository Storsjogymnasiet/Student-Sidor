internets historia

arpanet

arpanet var första stora nätverket. arpanet skapades eftersom att det fanns ett behov av ett decentraliserat nätverk som kunnde dela information över stora distanser. år 1969 skickades det första meddelandet på arpanet, det tog bara två bokstäver sedan krashade det. tcp/ip skapades på arpanet år 1983

vem sapade vörld vide väbb

Tim Berners Lee skapade webben när han jobbade på cern. webben består av massor av dokument med länkar till varandra i dem.

vilken var första websidan

cern websidan var första websidan. den skapades 1991 av Tim Berners Lee. webbsidan har information om world wide web projectet.

vilken var första webläsaren

mosaic web browser var den första browsern. den skapades av ncsa år 1993.

vad är ip och dns

ip adresser är afresser till olikka hosts. dns översätter namn på webbplatser till ip adresser som datorn kan avnända.
